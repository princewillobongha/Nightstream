# Nightstream Video Platform

Source synced from the current AppDeploy project snapshot.

## Stack
- React + TypeScript + Vite
- Tailwind CSS
- AppDeploy backend SDK routes

## Development
```bash
npm install
npm run dev
```

Build with `npm run build`.

## Current status
This is a design prototype. The adult declaration screen and empty video-library UI are present. Supabase authentication/database and Bunny Stream secure upload/playback integrations still need to be configured. No demo videos are included.

Never commit credentials, API keys, or environment secret values to this repository.
